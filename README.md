# GeraKStore Manager

Рабочая кухня GeraKStore. Снаружи красиво, внутри как обычно.

Здесь GeraKStore получает новые приложения и немного внимания.

## Что здесь происходит

Manager нужен для повседневной работы с GeraKStore: добавления приложений, подготовки данных и обновления каталога.

Если Store это витрина, то здесь та самая кухня, где всё это собирается.

## Связь с экосистемой

- [GeraKStore](https://github.com/gkuhtov/GeraKStore) - основной каталог
- [GeraKStore-Web](https://github.com/gkuhtov/GeraKStore-Web) - веб-версия каталога
- [GeraKStore-Welcome](https://github.com/gkuhtov/GeraKStore-Welcome) - welcome-экран
